# Legal Case Management System (LCMS)

## About Us

LexTrack is a web-based Legal Case Management System built with HTML, CSS, JavaScript, and PHP.
It helps lawyers and clients manage legal cases, track hearing dates, and stay organized — all in one place.

This project was built as part of Assignment.

---

## What LexTrack Can Do

- **User Registration & Login** — Separate access for Lawyers and Clients
- **Case Management** — Create and manage legal cases with full details
- **Hearing Tracking** — Never miss an upcoming court hearing date
- **Dashboard** — Live stats showing open, in-progress, and closed cases
- **Client Management** — Lawyers can see all their assigned clients
- **Role-Based Access** — Lawyers and clients only see what belongs to them
- **Contact Page** — Users can send messages directly through the platform

## Project Structure

```
lextrack/
├── controller/       # JavaScript logic (auth, dashboard, navigation, etc.)
├── data/             # JSON data files (users and cases)
├── model/            # Data store (fetch and save functions)
└── view/             # HTML pages, CSS styles, and PHP backend scripts
```

---

## How to Run This Project Locally

1. Make sure you have **XAMPP** installed on your computer
2. Copy the `lextrack` folder into `C:\xampp\htdocs\`
3. Start **Apache** from the XAMPP Control Panel
4. Open your browser and go to: `http://localhost/lextrack/view/index.html`
